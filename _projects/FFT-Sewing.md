**The Goal:** Characterize how the vibration signature of a treadle sewing machine changes across maintenance and fault conditions, using Fast Fourier Transform (FFT) analysis of recorded vibration signals.

**My Role:** Designed and executed an experimental vibration-monitoring study, applying signal processing techniques to diagnose mechanical faults before failure.

**Project Summary:**
- Captured vibration data across varying thread tension and load for a well-maintained machine, a poorly maintained machine, and a machine with induced faults (loosened bobbin case, unbalanced hand wheel, loosened feed dog).
- Used FFT to break each recording into its frequency components, making it possible to compare "healthy" and "faulty" signatures side by side.
- Found that a loosened bobbin case caused the needle to break, an unbalanced hand wheel barely changed performance, and a loosened feed dog produced a distinct vibration pattern — showing FFT's value as a non-invasive condition-monitoring tool.

**Skills Developed:** Signal Processing, Fast Fourier Transform (FFT), Vibration Analysis, Condition Monitoring, Experimental Design, Data Analysis
